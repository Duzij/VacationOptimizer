What this site is

Vacation Optimizer is a free, privacy-first holiday optimizer and PTO optimizer that turns scattered public holidays, weekends, and local calendar rules into longer, more useful breaks. You pick a country, year, and vacation-day allowance; the planner returns ranked time-off ranges around public holidays, with an annotated calendar, custom free days, monthly caps, locked days, regional/state/city holidays, and shareable plan links. No account required; planner data stays in the browser.
